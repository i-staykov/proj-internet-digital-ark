## 1. What this project is, in one paragraph

Prof. Xiaowei Ding maintains a benchmark corpus of domain names that existed between 1996 and 2001, as
six annual text files. Contributors submit additions; he merges, deduplicates and reports what he
accepted. This repository is one contributor's pipeline: it finds dated historical sources, extracts
`(domain, year)` claims from them, stores each claim beside the observation that proves it, and packages
a delivery archive. Four rounds have been accepted, none rejected.

## 2. The one hard problem, and it is arithmetic rather than effort

**A submission is only allowed at 5% growth or above.** Everything else is subordinate to that.

The threshold recedes because other contributors keep growing the corpus, measured at 1,082,013 EE/day

**So the engines cannot get there and no amount of running them will.** Phase 5 did reach 195,779 EE/day,
but by landing two bulk dated corpora, not by querying. **The only thing that produces a submittable
round is a bulk dated corpus worth roughly 600,000 equivalent-English.** If you take one instruction from
this file, take that one: do not spend a week tuning a collector.

Seven source families were screened on the last working day and every one was already closed on a sound
measurement. **There is no known candidate of that size on the list.** That is the honest state, and
finding one is the job.

## 3. How the evidence model works, and why it is strict

`domain_year.evidence_id` is `NOT NULL` with a foreign key into `evidence`. No code path can write a year
assignment without naming the observation supporting it. This is what lets an unattended agent be given
latitude about *what to try* and none at all about *what counts as proof*.

- A **master-eligible** evidence type may assign a year: `prior_reused`, `cdx_timestamp`,
  `artifact_listing`, `link_source`, `dated_directory`, `whois_creation`.
- **`link_target` never can.** Extracted hostnames are candidate-only by construction. They enter the
  candidate pool, get queried against the Wayback CDX index, and earn a year from the capture the engine
  finds, on that domain's own evidence. This is the discovery loop, and it needs no human approval.
- **The corroboration split**: anything a human typed is admitted only if another source already dates
  that domain. Self-dating records take no split. So widening extraction over prose is safe; widening it
  over a self-dating corpus is not.
- **The approval gate**: a master-eligible class cannot date a year until a human writes a `Decision:`
  line in `docs/approved-sources-list.md`. `ark ingest` enforces it and exits 2. **An agent arguing that
  its own find is master evidence is the least trustworthy artifact in this system**, which is why the
  request is generated by `scripts/request_approval.py` from a seeded-random sample with live links, so a
  reviewer checks external evidence instead of reading an argument.

## 4. The layout

```
src/ark/            the package: store, canonical, sources, cdx, rdap, export, checks, stats
  sources.py        one SourceSpec per source: how to parse it, what evidence type it yields
  canonical.py      the single funnel every hostname passes through
  checks.py         eleven integrity invariants; `ark check` runs them
  baseline.py       WHICH RELEASE IS CURRENT. Nothing else may hardcode it
scripts/            collectors, pricing, queue building, packaging, reporting
docs/               sources.md (the register), approved-sources-list.md (the gate), key-decisions.md

```

## 5. Running it

```bash
just cycle          # the health check: collectors, yields, unbanked journals, stale lists, approvals
just state          # regenerate docs/ROUND.md
just screen         # check a candidate source against the register before proposing it
uv run ark export && uv run ark check      # export first, always: one invariant reads the export
uv run python scripts/round_figures.py --verify   # re-score with HIS calculator; never send without it
just ship-approved  # bank approvals, regenerate the report, export, gate, package, verify
```

`README.md` documents every command and what each should print. Keep it current in the same sitting as
any change that adds one.

**The collectors are shell supervisors that run without an agent.** `scripts/supervise_cdx_pool.sh` and
`scripts/rdap_pool_sweep.sh` take their own absolute deadlines and keep going with nobody watching. That
property is what made unattended stretches safe. They are **stopped** as of the handoff; restart one only
if you have a reason, and remember that a queue file is read at batch start, so a rebuilt queue reaches a
running collector only if it was started on that path.

**On the previous harness.** The Claude setup drove itself with background timers and a cron wake, and
step 5 of that loop was "hunt for a new source every wake, without exception". None of that machinery is
needed. The equivalent is simply: run `just cycle`, act on what it says cannot be decided by a program,
then look for a bulk source. If your environment offers scheduled runs, point them at `just cycle`.

## 6. What has already been tried, so you do not repeat it

`docs/sources.md` holds every source and **112 closed families**, each with the measurement that closed
it. Check it before proposing anything. The shapes that actually paid:

| source | the dated artifact | scale |
|---|---|--:|
| `early_web_cdx` | Internet Archive capture timestamps | 2,160,814 domains |
| `isc_survey` | dated DNS survey editions | 1,314,476 |
| `domain_creation_bulk` | published registry creation dates | 2,165,523 pairs |
| `dartmouth_nber_captures` | a precomputed IA capture census | 227,273 pairs |
| `usenet_announce` | a Usenet post's own date | 335,504 domains |

**Every large win has the same shape: a corpus where each item carries its own date and mentions
hostnames.** The fastest filter available is that if you cannot say in one sentence what dates an
individual item, the source is seed-only and the conversation is over.

Five laws learned the expensive way, all in `docs/discovery.md`: an IA-derived source cannot be net-new
against an IA-derived baseline; a dated listing proves the artifact's date, not the site's liveness; a
corpus assembled by an infrastructure decision selects for authorities rather than hosts; and the
corroboration split is not a novelty check.

## 7. What to do next, ranked

1. **Hunt bulk dated corpora, and only bulk ones.** Registry datasets publishing creation dates as open
   data, national web-archive link graphs whose in-window rows are not an IA donation, academic
   replication packages from 1997-2003 web-scale research. Price with `scripts/price_items.py`, screen
   with `just screen`, and record the result in `docs/approved-sources-list.md` whatever the answer.
2. **The route Ivo has not yet authorised**: writing researchers and agencies to ask whether an unpublished
   early-web crawl or link graph can be shared. It is the only lead plausibly worth 600,000 EE. It waits
   on him under `## OPEN` in `docs/key-decisions.md`.
3. **Revisit ADR/decision C-24 against trailing rates rather than lifetime ones.** The candidate pool fell
   to 9.1% in-window on its recent answers against 47.6% lifetime, while an edge-year pilot returned
   80.9%. The comparison that closed C-24 was made while the pool was still paying. **Measure net-new
   value against a snapshot frozen before ingest**, because measuring it against the live store returns
   zero by construction for any journal already banked.
4. **Do not build a name-shape filter** without a positive control of known-real names. Three were
   designed in one afternoon and all three would have deleted real domains.
