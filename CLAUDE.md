# Internet Digital Ark

**The standing brief lives in [.github/copilot-instructions.md](.github/copilot-instructions.md).**

It was moved there on 2026-08-18 when the project was handed to GitHub Copilot, which reads that path
automatically. There is deliberately **one** copy of the rules rather than a Claude version and a Copilot
version, because two copies of a rule drift and the evidence rules are the last thing that should.

Read, in this order:

1. `.github/copilot-instructions.md` for the rules, which are non-negotiable.
2. `handoff-copilot.md` once, for the orientation: what exists, what has been tried, what to do next.
3. `docs/ROUND.md` for where the round stands. It is generated; never edit it.
4. `docs/key-decisions.md` for anything waiting on Ivo.

`handoff-ivo.md` is written for Ivo rather than for an agent.
