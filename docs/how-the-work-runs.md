# How the work runs

**One page on who does what, where each thing lands, and what only Ivo can do.** Written because
the machinery grew faster than the map of it (2026-09-03). If this page and the code disagree, the
code is right and this page is a bug.

## The three places work happens

| where | what it does | needs the laptop |
|---|---|---|
| **a session with the agent** (this repo, `live`) | everything that changes the store, the register or the deliverable: pricing a corpus, an ingest, an export, a package, a commit | yes |
| **the fleet** (`i-staykov/ark-fleet`, two self-hosted runners on the VPS, GitHub Actions schedule) | proposes hypotheses, screens and prices them read-only, re-opens closed verdicts, summarises, tunes its own policy | no |
| **the collectors** (systemd units on the VPS) | long CDX sweeps that write journals | no |

The fleet never touches the store. It clones `live` fresh on every wave, reads the shipped files
that `just bank` rsyncs to the VPS, and writes **findings**: one small markdown file per hypothesis
with a verdict and a figure. Nothing it finds is a record until a session banks it.

## The loop, and where each step leaves a mark

1. **Discover.** A lens proposes a source. Fleet generator, or a session, or Ivo. Lands in
   `ark-fleet/hypotheses.md` as an open block.
2. **Screen.** Does it collide with a closed family, and what dates one item? `just screen`. A
   collision prints the measurement that killed it, so nobody re-argues it.
3. **Price.** Net-new equivalent-English against the live store and against the reviewer's own
   files, never gross. `just price` for registrable grain, `just price-hosts` for hostname grain.
   Read-only, so it is safe while collectors run.
4. **Decide.** Under the standing rule of 2026-08-29 the loop writes its own `Decision:` line when
   all four conditions hold. Otherwise the source parks as `pending` in
   `docs/approved-sources-list.md` and waits for Ivo. **This is the main queue that only he can
   drain.**
5. **Ingest.** `ark ingest` / `ark ingest-hostnames`, which refuse any class without a decision.
   Every source gets its link and its dating sentence in `docs/sources.md` first.
6. **Export.** `ark export` writes the shipped files under `output/netnew/`: six annual registrable
   files, six hostname files, the evidence manifests, the candidate pool. Three rules decide what
   ships: not already in his files, not `.arpa` or a pre-delegation TLD, and not a `www.` alias of
   a name already held that year (ADR-007, under review).
7. **Check.** `ark check`, eighteen data invariants. Green is a precondition for every commit.
8. **Package and send.** `just ship` builds the archive, verifies it as a reviewer would, re-scores
   it with his own calculator, writes the mail draft and stops. **Sending is always Ivo** (C-63).
9. **Intake.** His next release arrives: `just intake <zip>` verifies, extracts, remeasures with his
   calculator and repoints `data/baseline.json`; `ark ingest-legacy` loads it. The denominator moves,
   so this comes before any new pricing.

## What only Ivo can do

- **Decide a source class.** A `Decision:` line the standing rule cannot write.
- **Send anything to the reviewer.** Packaging is automatic, sending is not.
- **Merge a PR.** `main` is reached only by a PR, on both repositories, and the agent never pushes it.
- **Approve a deletion** of code or data (the single table, C-61).
- **Answer a question the documents cannot.** Two are open: whether the 0903 scoring revision
  re-scores rounds already awarded, and whether a `www.` hostname beside its bare name is two
  records. His merges say yes to the second; we are holding 201,767.94 EE on it.

## What the agent does without being asked

Runs the gate before every commit, keeps the register honest (a negative is logged as carefully as
a find), refuses to quote a figure that does not come from the shipped files, and writes
`private/handoff.md` at every pause so the next session starts where this one stopped.

## The shape of a good day

The fleet proposes and prices while nobody watches. A session banks what cleared the bar, books the
negatives, and leaves one clean commit per logical unit on `live`. Ivo drains the decision queue,
merges, and sends. The round's percentage grows, his next release resets the denominator, and the
score now falls with every day of delay: since 2026-09-03, `t_i` counts whole calendar days from
the day the task was first assigned and never resets, so an early partial submission beats a late
complete one.
